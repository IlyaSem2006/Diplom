### Глоссарий терминов проекта

**Основные термины системы:**

* **КБЖУ** — калории, белки, жиры, углеводы (основные показатели пищевой ценности продукта)
* **BMR** — базовый метаболизм (базальный обмен веществ)
* **TDEE** — общий расход энергии за день
* **Дневной рацион** — совокупность продуктов, потреблённых за сутки
* **Приём пищи** — организованное потребление пищи (завтрак, обед, ужин, перекус)

**Технические термины:**

* **ORM** — Object-Relational Mapping (технология отображения объектов на реляционную базу данных)
* **API** — Application Programming Interface (программный интерфейс приложения)
* **REST** — Representational State Transfer (архитектурный стиль)
* **JSON** — формат обмена данными
* **HTTP** — протокол передачи данных

**Компоненты системы:**

* **Frontend** — клиентская часть приложения
* **Backend** — серверная часть приложения
* **БД** — база данных
* **ORM-модель** — объектная модель для работы с базой данных
* **Миграция** — процесс обновления структуры базы данных

**Пользовательские сущности:**

* **Профиль пользователя** — персональные настройки и данные пользователя
* **Запись питания** — информация о потреблённых продуктах
* **Цель пользователя** — заданные параметры для достижения (вес, калории)
* **Достижение** — награда за выполнение определённых условий
* **Уровень пользователя** — показатель активности в системе

**Функциональные термины:**

* **Аутентификация** — процесс подтверждения личности пользователя
* **Авторизация** — предоставление прав доступа
* **Валидация** — проверка корректности данных
* **Хеширование** — преобразование пароля в зашифрованный формат
* **Сеанс** — период работы пользователя с системой

**Термины базы данных:**

* **Таблица** — структурированное хранилище данных
* **Запись** — строка в таблице
* **Поле** — столбец в таблице
* **Индекс** — структура для ускорения поиска
* **Внешний ключ** — связь между таблицами

**Тестирование:**

* **Юзабилити** — удобство использования
* **Модульное тестирование** — проверка отдельных компонентов
* **Интеграционное тестирование** — проверка взаимодействия компонентов
* **Нагрузочное тестирование** — проверка работы при высокой нагрузке
* **Регрессионное тестирование** — проверка после внесения изменений

**Безопасность:**

* **CSRF** — Cross-Site Request Forgery (межсайтовая подделка запроса)
* **SQL-инъекция** — уязвимость в системе безопасности
* **SSL** — протокол для шифрования данных
* **Хеширование** — способ защиты паролей
* **Авторизация** — контроль доступа к данным

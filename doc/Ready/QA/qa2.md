### Вопросы и ответы для защиты проекта

**1. Общие положения и актуальность**

* **Вопрос:** В чем актуальность разработки данного приложения?
* **Ответ:** Актуальность обусловлена растущей проблемой избыточного веса и ожирения. По данным ВОЗ, более 2,5 млрд человек имеют избыточный вес. Приложение помогает контролировать питание и формировать здоровые привычки.

* **Вопрос:** Какие проблемы решает ваше приложение?
* **Ответ:** Решает проблемы ручного учета питания, отсутствия наглядной статистики, сложности в расчете КБЖУ, необходимости специальных знаний о пищевой ценности продуктов.

**2. Анализ предметной области**

* **Вопрос:** Какие основные сущности выделены в предметной области?
* **Ответ:** Основные сущности: пользователи, продукты, записи потребления, профили пользователей, система уровней и достижений.

* **Вопрос:** Почему был выбран именно такой набор функциональных требований?
* **Ответ:** На основе анализа аналогов и потребностей целевой аудитории. Включены базовые функции учета питания, расчета КБЖУ, ведения дневника и аналитики.

**3. Технические решения**

* **Вопрос:** Почему был выбран стек Flask + PostgreSQL?
* **Ответ:** Flask обеспечивает гибкость и простоту разработки, PostgreSQL гарантирует надежность хранения данных и высокую производительность.

* **Вопрос:** Какие преимущества дает использование ORM?
* **Ответ:** ORM упрощает работу с базой данных, обеспечивает безопасность запросов, позволяет легко менять СУБД при необходимости.

**4. Архитектура системы**

* **Вопрос:** Опишите архитектуру приложения
* **Ответ:** Клиент-серверная архитектура с разделением на:
  * Фронтенд (HTML, CSS, JavaScript)
  * Бэкенд (Flask)
  * СУБД (PostgreSQL)

* **Вопрос:** Как обеспечивается безопасность данных?
* **Ответ:** Через:
  * Хеширование паролей
  * Валидацию входных данных
  * Параметризованные запросы
  * CSRF-защиту

**5. Функциональность**

* **Вопрос:** Какие основные функции реализованы?
* **Ответ:** 
  * Регистрация и авторизация
  * Ведение дневника питания
  * Расчет КБЖУ
  * Статистика и визуализация
  * Система достижений

* **Вопрос:** Как работает система расчета КБЖУ?
* **Ответ:** Используются формулы расчета на основе веса продукта и данных о пищевой ценности из базы.

**6. Тестирование**

* **Вопрос:** Какие виды тестирования проводились?
* **Ответ:** 
  * Модульное
  * Интеграционное
  * Юзабилити
  * Нагрузочное
  * Тестирование безопасности

* **Вопрос:** Как обеспечивается качество кода?
* **Ответ:** Через:
  * Unit-тесты
  * Code review
  * Соблюдение стандартов кодирования
  * Документирование

**7. Перспективы развития**

* **Вопрос:** Какие планы по развитию проекта?
* **Ответ:** 
  * Добавление распознавания продуктов
  * Интеграция с фитнес-трекерами
  * Внедрение AI-аналитики
  * Разработка мобильного приложения
  * Расширение базы продуктов

**8. Экономические аспекты**

* **Вопрос:** Какова экономическая эффективность проекта?
* **Ответ:** Проект бесплатен для пользователей, монетизация возможна через премиум-функции и партнерские программы.

**9. Практическая значимость**

* **Вопрос:** Как результаты проекта могут быть использованы на практике?
* **Ответ:** Приложение может использоваться:
  * Частными лицами для контроля питания
  * Специалистами по питанию
  * В медицинских учреждениях
  * В фитнес-центрах

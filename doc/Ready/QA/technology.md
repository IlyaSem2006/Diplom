### Технологии, использованные в проекте

**Веб-фреймворки и серверные технологии:**
* **Flask** — микрофреймворк для Python, обеспечивающий:
  * маршрутизацию URL
  * обработку запросов
  * работу с шаблонами
  * интеграцию с расширениями

* **Gunicorn** — WSGI-сервер ((eb Server Gateway Interface) для:
  * асинхронной обработки запросов
  * балансировки нагрузки
  * мониторинга работы

**Базы данных:**
* **PostgreSQL** — реляционная СУБД, обеспечивающая:
  * надёжное хранение данных
  * поддержку транзакций
  * расширенные типы данных
  * полнотекстовый поиск

* **SQLAlchemy** — ORM-библиотека для:
  * работы с БД через Python
  * миграции схемы
  * управления сессиями

**Клиентские технологии:**
* **HTML5** — для создания структуры веб-страниц
* **CSS3** — для стилизации и адаптивного дизайна
* **Bootstrap 5** — для:
  * отзывчивого дизайна
  * готовых компонентов интерфейса
  * унификации стилей

**Python-библиотеки:**
* **Psycopg2** — драйвер для работы с PostgreSQL:
  * нативная реализация на C
  * поддержка транзакций
  * защита от SQL-инъекций

* **Werkzeug** — инструментарий для:
  * отладки
  * обработки запросов
  * работы с сессиями

* **Python-dotenv** — для:
  * управления конфигурацией
  * хранения секретов
  * изоляции настроек

**Инструменты разработки:**
* **Flask-Login** — для:
  * управления сессиями
  * аутентификации пользователей
  * защиты маршрутов

* **Flask-SQLAlchemy** — для:
  * объектно-реляционного отображения
  * работы с БД
  * миграций

**Тестирование:**
* **unittest** — встроенный фреймворк для модульного тестирования
* **pytest** — для:
  * написания тестов
  * параметризации
  * фикстур

* **Selenium** — для:
  * автоматизации браузера
  * тестирования UI
  * проверки функциональности

**Визуализация:**
* **Chart.js** — для создания:
  * графиков потребления
  * диаграмм распределения КБЖУ
  * визуальной аналитики

**Безопасность:**
* **Werkzeug** — для:
  * хеширования паролей
  * защиты от CSRF
  * безопасной работы с данными

* **Flask-WTF** — для:
  * валидации форм
  * защиты от инъекций
  * обработки данных
